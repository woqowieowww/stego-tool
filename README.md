# stego-tool

![Bash](https://img.shields.io/badge/Bash-4EAA25?logo=gnubash&logoColor=white)
![Platform](https://img.shields.io/badge/platform-Linux%20%7C%20macOS%20%7C%20WSL-lightgrey)

**Универсальный стеганографический консольный инструмент на Bash.** Прячет текст или файл внутри любого другого файла — изображения, видео, архива — и достаёт обратно.

## Как это работает

Данные дописываются в **конец** файла-контейнера (метод *append*) вместе с заголовком:

```text
[ исходное содержимое контейнера ][ STEGO ][ длина, 4 байта ][ скрытые данные ]
```

Содержимое контейнера не меняется, поэтому картинка или видео открываются как обычно. Размер выходного файла становится больше исходного.

## Возможности

- `--embed` — встроить текст (`-d`) или файл (`-f`) в контейнер;
- `--extract` — извлечь данные на экран или в файл;
- `--info` — проверить, есть ли в контейнере скрытые данные;
- интерактивное меню при запуске без аргументов;
- работает с любым форматом контейнера.

## Требования

- `bash`
- `dd`, `xxd`, `grep`, `od`, `stat`

## Установка и запуск

```bash
git clone https://github.com/woqowieowww/stego-tool.git
cd stego-tool
chmod +x stego_tool.sh
./stego_tool.sh              # интерактивное меню
./stego_tool.sh --help       # справка
```

## Примеры

Спрятать текст в картинку и прочитать его:

```bash
./stego_tool.sh --embed -c photo.jpg -d "Привет, мир!" -o photo_secret.jpg
./stego_tool.sh --extract -c photo_secret.jpg
```

Спрятать файл в видео и достать обратно:

```bash
./stego_tool.sh --embed -c video.mp4 -f archive.zip -o video_with_zip.mp4
./stego_tool.sh --extract -c video_with_zip.mp4 -o extracted.zip
```

Проверить, есть ли в файле скрытые данные:

```bash
./stego_tool.sh --info -c video_with_zip.mp4
```

## Параметры

| Параметр | Описание |
|---|---|
| `--embed` | встроить данные в контейнер |
| `--extract` | извлечь данные из контейнера |
| `--info` | показать информацию о контейнере |
| `-c КОНТЕЙНЕР` | файл-контейнер |
| `-d "ТЕКСТ"` | встраиваемый текст |
| `-f ФАЙЛ` | встраиваемый файл |
| `-o ВЫХОДНОЙ` | выходной файл (без него `--extract` печатает данные на экран) |
| `--help` | справка |

## Ограничения

- Максимальный размер скрытых данных — около 4 ГБ (длина хранится в 4 байтах).
- Для бинарных данных используйте режим командной строки с ключом `-f`: в интерактивном режиме возможна потеря данных.
- При выводе бинарных данных на экран терминал может «сломаться». Сохраняйте их в файл (`-o`); если терминал всё же завис, наберите `reset`.
- Повторное встраивание добавляет ещё один блок в конец файла, старые данные остаются. При извлечении берётся последний блок.

> [!IMPORTANT]
> Это маскировка, а не шифрование. Любой, кто знает формат или просто посмотрит конец файла, найдёт данные. Для секретной информации сначала зашифруйте её.
